# EJSCREEN data pull

Pulled: 2026-10-14

- **File**: `EJSCREEN_2024_BG_with_AS_CNMI_GU_VI.csv` (417 MB, 243,023 rows — one per census block group, plus territories)
- **Source**: Harvard Dataverse, "Environmental Justice Mapping and Screening Tool (EJScreen)", Version 4.0 (2024) — https://doi.org/10.7910/DVN/RLR5AX
- **Direct download URL used**: `https://dataverse.harvard.edu/api/access/datafile/10775972`
- **License**: CC0 1.0
- **Original publisher**: U.S. EPA. EPA's own EJSCREEN tool and downloads were taken offline 2025-02-05; this is a third-party-hosted mirror of EPA's own data, not an EPA-maintained source.
- **Key columns**: `STATE_NAME`, `ST_ABBREV`, `CNTY_NAME`, `DEMOGIDX_2`/`DEMOGIDX_5` (demographic index), `LOWINCPCT`, `PEOPCOLORPCT`, plus environmental indicators (PM2.5, ozone, diesel particulate matter, proximity to hazardous sites, etc.) and their percentile scores. See EPA's own technical documentation (also archived on the same Dataverse page) for full column definitions.
