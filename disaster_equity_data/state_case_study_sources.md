# State case-study sources: cost, political, and administrative feasibility

Textual sources (GAO reports, legislative history, program documentation,
delegation/governor/legislature action) supporting the memo's qualitative
case studies, gathered to pair with the quantitative state-level data in
`aggregated/`. Six states were researched in parallel by separate
subagents, each instructed to only cite sources it could verify were real —
sources it couldn't confirm are noted as gaps, not guessed at.

**Scope: documents published 2017–2026 only.** An earlier version of this
file included older sources (back to 1988); those were dropped in this
revision to keep the case studies focused on the current policy landscape.
First pull: 2026-10-15. Delegation/governor/legislature documents added:
2026-10-22.

Two groups, based on the funding-vs-vulnerability pattern in
`aggregated/openfema_funding_by_state_2017_2026.csv` joined against
`aggregated/cejst_by_state.csv` / `aggregated/ejscreen_by_state.csv`:
- **High-vulnerability, high-funding**: Louisiana, Kentucky, Mississippi
- **High-vulnerability, low-funding**: Oklahoma, West Virginia, Arkansas

## Cross-cutting gaps for the memo to flag

- The "low-capacity states get disadvantaged by BRIC" argument rests on **national** GAO/Headwaters Economics evidence applied to Oklahoma, West Virginia, and Arkansas — no state-specific GAO audit exists for any of the three.
