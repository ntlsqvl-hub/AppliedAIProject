Methodology

Where this data comes from

Four external sources feed this project. Each entry below names the origin site, briefly describes how the data was obtained from it, and links out to that original source directly. For where the resulting files live in this project's own repository, see the Home page.

  • OpenFEMA

    fema.gov/about/openfema ↗

    FEMA's own Public Assistance and Hazard Mitigation funding records, broken out by state, disaster, and program.

    How it was obtained: queried directly from OpenFEMA's public REST API (PublicAssistanceFundedProjectsSummaries and HmaSubapplications endpoints), filtering on declaration date and fiscal year to the 2017–2026 window, with no authentication required.

  • CEJST

    public-environmental-data-partners.github.io ↗

    The Climate and Economic Justice Screening Tool, which flags census tracts as disadvantaged based on environmental, health, and economic burden indicators.

    How it was obtained: the original CEQ-hosted tool was taken offline; this project downloaded the Version 2.0 communities CSV directly from the Public Environmental Data Partners' community-maintained mirror's public downloads page.

  • EJSCREEN

    dataverse.harvard.edu ↗

    EPA's environmental justice screening tool, combining pollution and demographic indicators at the census block-group level.

    How it was obtained: EPA discontinued public access to EJSCREEN in February 2025; this project downloaded the Version 4.0 (2024) national block-group file directly from Harvard Dataverse's file-access API, where a researcher had archived EPA's own release.

  • Federal Register

    federalregister.gov/developers ↗

    The official daily journal of federal agency rules, proposed rules, and notices.

    How it was obtained: queried via the Federal Register's public REST API, filtering to EPA Rules and Proposed Rules published in 2025 that mention "extreme weather" or "community" in their full text, with no authentication required.
